# “融合感知”智慧交通车辆环境监测与预警系统

> 基于 Arduino Nano 的盲区监测、雨雾环境感知与变道辅助演示平台。

本系统以 Arduino Nano 为主控，围绕“感知—决策—反馈”构建一套可触摸的车辆安全功能演示装置：红外模块监测侧后方盲区，AHT20 采集环境温湿度以模拟雨雾天气，VL53L0X 监测前方距离与接近速度，多色 LED 与有源蜂鸣器提供声光反馈，A0 按键模拟驾驶员变道请求。

系统上电即独立运行，不依赖上位机；串口以 9600 bps 输出距离、接近速度与湿度数据，便于调试和演示。

## 功能特性

| 功能 | 触发条件 | 反馈 |
| --- | --- | --- |
| 系统运行指示 | 上电初始化完成 | 蓝灯常亮 |
| 盲区障碍警示 | 红外模块 OUT = 低电平 | 黄灯常亮，最高优先级 |
| 雨雾/湿度警示 | 相对湿度 > 85% 开；< 75% 关 | 白灯常亮，85%/75% 迟滞 |
| 安全变道 | 盲区无障碍 + 按下 A0 | 绿灯点亮 1 s |
| 危险变道 | 盲区有障碍 + 按下 A0 | 红灯快闪 1.5 s + 蜂鸣器短鸣 |
| 快速逼近预警 | 距离 < 800 mm 且接近速度 > 1000 mm/s | 红灯 150 ms 周期闪烁 + 蜂鸣器 |
| 串口监视 | 系统运行期间持续输出 | 距离、速度、湿度 |

补充说明：

- **黄灯为常驻提示**。主循环每一轮都会根据红外输入刷新黄灯，不受按键、白灯或其它状态影响；只要盲区有障碍，黄灯不会熄灭。
- **白灯带迟滞**。湿度高于 85% 点亮，低于 75% 才熄灭，避免临界湿度附近频繁闪烁。
- **红灯有两个来源**：雷达快速逼近预警，以及“有障碍时请求变道”。雷达预警的优先级更高；雷达报警期间不响应新的变道请求。
- **按键采用内部上拉**。A0 与 GND 之间接轻触按键，按下为低电平；代码在按下时锁定，松开后解锁，避免连按重复触发。
- **串口输出**。距离无效（超时、≤ 0 或 > 2000 mm）时按 -1 处理；速度经过 0.7/0.3 平滑，抑制传感器抖动。

| AHT20 SCL | A5 | 输出 | — | I2C 时钟 |
| VL53L0X SDA | A4 | 双向 | — | 与 AHT20 共用 I2C 总线 |
| VL53L0X SCL | A5 | 输出 | — | 与 AHT20 共用 I2C 总线 |

两路 I2C 器件地址不同（AHT20 为 0x38，VL53L0X 为 0x29），可以并联在同一条 A4/A5 总线上。

## 接线步骤

1. **断电接线**。先将 USB 线断开，所有模块与 LED 接好后再上电，避免带电插拔。
2. **布置电源轨**。把 Nano 的 `5V` 与 `GND` 分别接到面包板的红色 `+5V` 轨和黑色/蓝色 `GND` 轨；后续模块的 VCC、GND 均从这两条轨取电。
3. **连接 I2C 传感器**。AHT20 与 VL53L0X 的 `VCC` 接 +5V（VL53L0X 若为 3.3V 裸板则接 3V3），`GND` 接 GND，`SDA` 接 A4，`SCL` 接 A5；两个模块并联在同一组总线上。
4. **连接红外模块**。`VCC` 接 +5V，`GND` 接 GND，`OUT` 接 D11。模块上的电位器用于调节检测距离；检测到障碍时 OUT 输出低电平。
5. **连接蜂鸣器**。`VCC` 接 +5V，`GND` 接 GND，`IO` 接 D10。该模块为低电平触发，D10 输出低时鸣响。
6. **连接 LED**。五颗 LED 的阳极分别经 220Ω 电阻接 D9（蓝）、D7（白）、D4（黄）、D3（红）、D5（绿），阴极全部接 GND。LED 长脚为阳极，短脚为阴极。
7. **连接按键**。轻触按键一端接 A0，另一端接 GND；代码启用内部上拉，不需要外接上拉电阻。
8. **复核**。重点检查电源正负极、LED 极性、共地，以及 A4/A5 是否接反；确认无误后再插入 USB。

## 工作原理

系统上电后依次完成：

1. 配置输出引脚，蓝灯立即点亮，蜂鸣器保持关闭；
2. 配置 A0 为上拉输入、D11 为输入；
3. 初始化 I2C 总线、VL53L0X 与 AHT20；
4. 进入主循环，持续读取距离、湿度、红外与按键状态。

主循环的处理顺序与优先级如下：

1. **距离与速度**：VL53L0X 以 50 ms 周期连续测距；距离无效时记为 -1。相邻两次有效距离用于计算接近速度，并按 `0.7 × 旧值 + 0.3 × 新值` 平滑。
2. **湿度判断**：湿度 > 85% 时置白灯标志，< 75% 时清除，形成迟滞。
3. **盲区判断**：D11 为低则判定盲区有障碍，黄灯立即点亮；该判断独立于其它状态。
4. **快速逼近预警**：距离 < 800 mm 且平滑速度 > 1000 mm/s 时，红灯以 150 ms 周期闪烁（75 ms 亮、75 ms 灭），蜂鸣器同步鸣叫；该状态优先级最高。
5. **变道请求**：在非雷达预警状态下检测 A0 按下：
   - 盲区无障碍：绿灯点亮 1 s，表示允许变道；
   - 盲区有障碍：红灯以 200 ms 周期闪烁，蜂鸣器以 300 ms 周期短鸣，持续 1.5 s，表示变道危险。
6. **串口输出**：以 9600 bps 输出距离、平滑速度与湿度，便于观察传感器变化。

## 软件与烧录

**开发环境**：Arduino IDE 2.x。

**板卡选择**：

- Board：`Arduino Nano`
- Processor：`ATmega328P`；若使用常见克隆板且无法下载，改为 `ATmega328P (Old Bootloader)`
- Port：对应的 USB 串口

**依赖库**：

- `VL53L0X`（Pololu）
- `Adafruit AHTX0`
- `Adafruit BusIO`
- `Adafruit Unified Sensor`

**烧录步骤**：

1. 在 Arduino IDE 中安装上述库；
2. 打开项目主程序（`.ino`）；
3. 选择板卡、处理器与串口；
4. 编译并上传；
5. 打开串口监视器，波特率设为 `9600`，即可看到距离、速度与湿度数据。

主程序的核心引脚定义与本文《引脚分配》一致；如更换引脚，请同步修改代码与图纸。

## 注意事项

- 五颗 LED 必须各自串联 220Ω 限流电阻，不能直接接到 5V 或 GPIO。
- LED 有极性：长脚为阳极，短脚为阴极；接反不会损坏，但不亮。
- 红外模块为 3 针，实物针脚顺序为 `OUT / GND / VCC`；不同批次可能不同，以丝印为准。
- 蜂鸣器模块为 3 针，实物针脚顺序为 `VCC / IO / GND`，低电平触发。
- VL53L0X 模块的 VCC 允许范围取决于具体 breakout：常见 GY-VL53L0XV2 支持 3–5V；若使用不带稳压的裸板，请接 3.3V。
- AHT20 模块通常支持 3.3–5V；以模块丝印为准。
- 所有模块必须共地，否则 I2C 与数字信号均可能异常。
- 图纸为模块级原理图，未展开模块内部电路；模块内部的上拉、稳压与电平转换按成品模块处理。
- 调试时先在串口确认距离与湿度数据正常，再测试按键与 LED，便于快速定位问题。
- 演示视频开头包含一次蜂鸣器上电自检提示；若当前固件未实现，可在 `setup()` 末尾将 D10 拉低约 100 ms 再拉高，即可得到同样的提示音。
